# Neo-Brutalist Portfolio - Implementation Plan

## Overview
A single-page Next.js + Tailwind CSS portfolio with 11 interactive components in a Neo-Brutalist / Retro-Terminal design language.

## Stack
- Next.js (App Router)
- Tailwind CSS v3
- React hooks (useState, useEffect, useRef)

## Components
1. Custom Cursor
2. Loading Screen
3. Sticky Nav Bar
4. Hero Section
5. Experience Timeline
6. Projects Grid
7. Skills Grid
8. Education + Drawing Canvas
9. Accordion Strips
10. Footer Marquee
11. Contact Modal
